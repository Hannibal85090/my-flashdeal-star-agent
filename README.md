# ⭐ My FlashDeal Star - Sovereign Financial AI Agent

An autonomous, multi-language Sovereign Financial Agent (SFA) designed for secure global currency transactions and live market analytics. Powered by high-fidelity voice execution and resilient web scraping infrastructure.

## 🎙️ Slogan
**Talk. Pay. Done.**

## 🛠️ Core Infrastructure
- **Agent Intelligence:** Python & Streamlit Cyber-Glassmorphism UI.
- **Market Context:** Driven by **Bright Data SERP API** for live, anti-blocking global exchange rate structures.
- **Voice Gateway:** Powered by **Speechmatics** high-fidelity engine to process multi-lingual direct commands.
- **Security:** Sovereign Mutual Token verification with Multi-layer Biometric sync fallback.

## 📁 Repository Structure
- `app.py`: Main interactive dashboard application.
- `core/security.py`: Sovereign identity token and biometric mock gateway.
- `services/live_market.py`: Bright Data real-time market data integration.
- `services/voice_gateway.py`: Speechmatics speech-to-text routing layer.
